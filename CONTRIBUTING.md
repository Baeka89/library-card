# Contributing

Report reproducible issues with Home Assistant, Library Card and relevant card
versions. Remove credentials and private data from examples and logs.

Keep the integration domain `card_library` and persisted storage compatible.
Use original card renderers/editors and preserve local exceptions. Run the
commands in README and all three GitHub workflows before a release.

Changes to publication automation need tests for failure paths and must not
submit a HACS request before successful HACS/hassfest checks and a public release.
